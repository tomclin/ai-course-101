## 一句話說完這門課

> **別練提問，練交接。**（Stop prompting, start briefing.）

大家用的 AI 其實都一樣強，差別只在——它認不認識你。AI 是一位第一天到職、聰明絕頂、但完全不認識你的新同事：你不會對新同事丟一句話就要成品，你會先讓他認識你。這門課只練這一個動作。

## 使用說明

- **課堂學員**：跟著講師走，當天每人先做 Level 1，再依程度選 Level 2 或 3。
- **自學者**：照順序讀投影片 → 做 Level 1 題卡 → 用滿一週 → 再挑戰 Level 2/3。每張題卡上都有步驟與完成判準。
- **列印**：題卡與對照表已針對 A4 排版，瀏覽器直接列印，每份一頁。
- **深／淺色**：所有頁面自動配合裝置的深淺色模式；列印一律輸出淺色。

## 三個誠實的原則

1. **工具不限**——ChatGPT、Gemini、Claude、Copilot 都行，**全部練習免費版可完成**（介面名稱查證日期：2026-07-10，各家官方說明中心）。
2. **AI 會錯**——這門課教它更懂你，不是讓它變得不會錯。重要的事，核對再用。
3. **脈絡卡寫「處境」不寫「機密」**——身分證字號、病歷、財務明細不要貼。

## 這門課的起源

課程開場的真實故事：一個還沒上大學的孩子，在電腦壞掉的情況下，把構想寫成「交接文件」，和 AI 一起在一天內做出了自己的駕照筆試練習 App——[taiwan-driving-test-prep](https://github.com/tomclin/taiwan-driving-test-prep)，也是開源的，歡迎自取。
