工具脈絡對照表——你的脈絡卡要貼哪裡？

四個工具都能完成今天全部練習，免費版就夠。先找到你在用的那一列。

掃碼開此表
工具 一次性貼脈絡（本堂課用這個就夠） 永久記住的位置（回家設定一次） 免費版限制
ChatGPTchatgpt.com 開新對話，直接把脈絡卡貼在最前面。 頭像 → 設定 → 個人化 → 自訂指令（先打開「啟用自訂功能」）。同頁另有「記憶」：它會自動記住你說過的事，可隨時「管理記憶」刪改。
⚠️ 手機／平板 App 與電腦網頁版的介面與選單路徑不一致，看到的內容也可能不同；找不到就在設定裡搜「個人化」（2026-08-07 講師實測）。		 自訂指令與記憶免費版都有。文字對話 2026 年 8 月起已無則數上限（防濫用限制仍在）；上傳檔案、生圖、語音另有額度。
Geminigemini.google.com 開新對話，直接貼。 選單 → 設定與說明 → 個人化智慧服務 → 「給 Gemini 的指令」（舊名 Saved Info／已儲存的資訊，2026 年改名）。同頁可開啟「根據對話記錄個人化」。 免費版都有（記憶功能需年滿 18 歲、開啟「保留活動紀錄」）。注意：在 Gem 裡不會套用這些指令，Gem 要另外寫自己的指令。另一張王牌：免費帳號可連接 Google Workspace（設定 → 個人化智慧服務 → 連結的應用程式）——能讀 Gmail／雲端硬碟、建立與管理日曆事件、加 Tasks 待辦、記 Keep 筆記；不能代寄信、不能建新文件。前置：Gmail「智慧功能」需開啟。
Claudeclaude.ai 開新對話，直接貼。 左下角頭像 → Settings（設定）→ 個人指示欄位（介面為英文）。想分主題管理：建一個 Project（專案），把脈絡卡放進專案指示。也有自動記憶，可在 Settings → Memory 檢視編輯。
✔ 手機／平板／電腦介面一致，跨裝置照同一路徑找即可（2026-08-07 講師實測）。		 個人指示與自動記憶免費版都有；專案免費版最多 5 個。「搜尋過去對話」功能需付費版。
Copilotcopilot.microsoft.com 開新對話，直接貼。 沒有指令欄位，改用講的：貼上脈絡卡後說「請記住這些」。查它記了什麼：問「你知道我哪些事？」。管理：頭像 → 記憶體 → 個人化和記憶體（中文介面真的叫「記憶體」，別被字面嚇到）。 登入個人 Microsoft 帳號即可用記憶功能，不需付費版。
通用備案：工具沒有記憶功能，或找不到上面的設定？把脈絡卡存在手機備忘錄，每次開新對話，開頭貼上，效果一樣。
進階 · 乾淨對照：已設定個人化的人想看真實的 before／after，測 before 時：ChatGPT 開「臨時交談」；Gemini 暫時關閉「根據對話記錄個人化」；Claude 在 Settings 暫時關閉記憶（或開一個新專案，各專案記憶互不相通）；Copilot 先問「你知道我哪些事？」確認它記了什麼再對照。
  • 各家介面改名頻繁，找不到時就在設定裡搜「個人化」或「記憶」。
  • 脈絡卡寫「處境」不寫「機密」：身分證字號、病歷、財務明細不要貼。
  • AI 認識你之後仍會出錯：重要決定（醫療、金錢、法律），核對原始來源再用。
